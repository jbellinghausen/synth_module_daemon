# Example prompts

Ready-made prompts for building apps on the synth module with an AI coding
assistant such as Claude Code. Each one tells the assistant where the project
lives, how to install the client, the hardware facts that matter, and how to
test without the Pi (using a local dry-run daemon).

To use one: start a new session in an empty folder, check the **Setup**
section (Pi address, which CV/gate slots are patched to what), and paste the
prompt.

| Prompt | Builds |
|--------|--------|
| [threejs-scale-kick.md](threejs-scale-kick.md) | three.js scale visualizer: a generated lead melody on one CV/gate pair and a four-on-the-floor kick on another |
